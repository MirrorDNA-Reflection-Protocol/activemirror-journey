# Topic Packets

Put long-running Active Mirror topic packets here.

Use [../TOPIC_PACKET_TEMPLATE.md](../TOPIC_PACKET_TEMPLATE.md) as the source template. A topic packet is for continuity, not strategy performance: current lane, user outcome, source material, rules, tools, proof, bad news, and next move.

`npm run mirror:context` automatically includes every Markdown file in this folder, so a future run can ingest active topics without Paul reconstructing the thread from memory.
