# Product Marketing Context

Product: Active Mirror

Status: internal working context for copy, onboarding, and UX decisions.

## Positioning

Active Mirror is a chat-first reflective AI for people who feel stuck, overwhelmed, or tired of AI that agrees too easily.

The first promise is not architecture. The first promise is movement:

> Say the thing. Get a clearer next move.

## Primary User Job

When someone arrives, assume they want one of these:

- get unstuck
- make messy thoughts usable
- check their thinking
- keep private context under their control

They do not arrive wanting to inspect the runtime, model route, ledger, or internal system design.

## Messaging Rules

Use normal language:

- What do you want?
- Make it yours.
- Saved in this browser.
- Download Mirror ID.
- You choose what carries forward.

Avoid consumer-facing internal language:

- kernel
- gateway
- route
- viewport
- widget
- MirrorSeed
- sovereign
- node of 1
- cryptographic receipt
- model/provider names

## Behavioral Design Rules

- Default to one obvious action.
- Use three or fewer starter choices.
- Let the user get value before setup.
- Use color for hierarchy, state, and emotional tone, not decoration.
- Do not rely on color alone to communicate meaning.
- Avoid fake urgency, scarcity, or manipulative conversion copy.

## Accuracy Boundary

BrainScan is preference calibration. It does not claim personality, diagnosis, or identity accuracy.

Mirror ID is a portable preference file generated from explicit choices.

## Conversion Goal

The desired first-session outcome is:

1. User sends or taps one real starting point.
2. User sees one useful reflection.
3. User optionally creates a Mirror ID.
4. User returns to reflection with those preferences active.
