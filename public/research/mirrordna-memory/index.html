MirrorDNA Memory Architecture

A sovereign, filesystem-based memory system for persistent AI identity across sessions, model switches, and multi-agent workflows.

Paul Desai · N1 Intelligence (OPC) Pvt Ltd · 2025–2026

The Memory Problem

Standard AI systems store memory in context windows — ephemeral, model-bound, lost at session end. MirrorDNA Memory is designed around the opposite principle: memory is permanent, model-agnostic, and stored in formats any agent can read.

Components

Memory Bus

Filesystem event log. Every agent action, decision, and output is written to the bus. Persistent across sessions and model switches.

CONTINUITY.md

Human-readable session state. Updated at every session boundary. Any model reads this to boot with full context.

OpenMemory (FAISS + SQLite)

Semantic memory layer. 295 memories seeded from canonical sources. Vector search over personal knowledge at 768 dimensions.

Vault (5,000+ notes)

The knowledge mesh. Markdown files with YAML frontmatter, wiki-links, and mesh IDs. Source of truth for all long-term knowledge.
